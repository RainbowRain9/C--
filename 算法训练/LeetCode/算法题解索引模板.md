# 算法题解索引模板

## 文件基本信息

1. 文件命名规范
- 格式: `XX-算法分类题解索引.md`
- 示例: `01-滑动窗口与双指针题解索引.md`

2. 文件头部信息
```markdown
# 算法分类题解索引

本索引基于[原始文档名称](../All/原始文档.md)整理，将题解按照类别进行分类。
```

3. 参考资料
```markdown
请先学习：[学习资源标题](资源链接)
```

## 分类组织结构

1. 主分类
```markdown
## 分类名称

[分类说明文字]

[重要概念解释]

[注意事项说明]
```

2. 子分类(可选)
```markdown
### 子分类名称

[子分类说明文字]
```

## 题目链接格式

1. 基本格式
```markdown
- [题号. 题目名称](../All/题号-题目名称.cpp)
```

2. 带空格的文件名
```markdown
- [题号. 题目名称](<../All/题号-题目名称.cpp>)
```

3. 特殊题目
```markdown
- [LCP XX. 题目名称](../All/LCPXX-题目名称.cpp)
```

## 题目信息展示

1. 基本题目
```markdown
- [题号. 题目名称](../All/题号-题目名称.cpp)
```

2. 带难度分的题目
```markdown
- [题号. 题目名称](../All/题号-题目名称.cpp) 难度分
```

3. 会员题目
```markdown
- [题号. 题目名称](../All/题号-题目名称.cpp)（会员题）
```

4. 带说明的题目
```markdown
- [题号. 题目名称](../All/题号-题目名称.cpp) 说明文字
```

5. 未完成题目
```markdown
- [题号. 题目名称](../All/题号-题目名称.cpp)❌
```

## 说明文字规范

1. 重要概念
```markdown
* 概念名称：概念解释。
```

2. 注意事项
```markdown
⚠**注意**：注意事项内容。
```

3. 补充说明
```markdown
注：补充说明内容
```

4. 代码示例
```markdown
* 示例：`代码片段`
```

## 使用说明

1. 根据算法类型选择合适的模板章节
2. 保持格式统一,内容精炼
3. 注重实用性和可理解性
4. 适当添加说明和示例
5. 突出重点,标注难点
