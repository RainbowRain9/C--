## 四、解题思路

### 1. 问题分析
- **问题的本质**：如何排列数字使得拼接后的字符串最大
- **可能的解决方案**：贪心算法、自定义排序
- **方案的优劣比较**：贪心算法简单高效，适合本题

### 2. 算法设计
- **核心算法选择**：自定义排序
- **数据结构设计**：使用字符串数组存储数字
- **优化思路**：直接比较字符串拼接结果

### 3. 解题步骤
1. **步骤一**：将数字转换为字符串
   - 实现细节：使用`vector<string>`存储
   - 注意事项：避免数字溢出
2. **步骤二**：自定义排序
   - 实现细节：比较`a+b`和`b+a`的大小
   - 注意事项：确保比较函数正确
3. **步骤三**：拼接结果
   - 实现细节：遍历排序后的数组拼接字符串
   - 注意事项：处理前导零

## 五、代码实现

### 1. 完整代码
```cpp
/**
 * @brief 最大整数拼接
 * @param n 数字个数
 * @param nums 数字数组
 * @return 拼接后的最大整数
 */
#include <algorithm>
#include <iostream>
#include <vector>
#include <string>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<string> nums(n);
    for (int i = 0; i < n; i++) {
        cin >> nums[i];
    }

    auto cmp = [](string &a, string &b) {
        return a + b > b + a;
    };

    sort(nums.begin(), nums.end(), cmp);

    string result;
    for (string &num : nums) {
        result += num;
    }

    cout << result << endl;

    return 0;
}
```

### 2. 关键代码段解析
```cpp

    return a + b > b + a;
};
// 自定义比较函数，比较两个字符串拼接后的大小
```
